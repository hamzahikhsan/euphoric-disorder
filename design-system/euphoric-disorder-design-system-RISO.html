01 — Brand

Kenapa
cetak?

euphoric.disorder adalah brand sablon bertema kriminologi. Maka design system-nya berbicara bahasa yang sama dengan produknya: tinta di atas kertas. Estetika ini — halftone, misregistrasi, overprint, cap, selotip — sulit dipalsukan oleh template generik karena ia meniru proses fisik, bukan efek digital.

The Case Files

Produk = barang bukti. Halaman = arsip. Review = keterangan saksi. Nada forensik yang serius tapi absurd. Motif nyata dari IG: #WarOnDrugs, adiksi, keadilan.

5 Prinsip

1. Kertas dulu, layar belakangan.
2. Ketidaksempurnaan = disengaja (misprint, miring).
3. Tinta terbatas, overprint bikin warna ketiga.
4. Tipografi besar & terpotong tepi.
5. Suara deadpan, bukan bahasa iklan.

Grid & Aturan

Grid: 12 kolom, max 1180px, gutter 24px. Boleh langgar grid sesekali (elemen miring/menonjol) — itu ciri zine.

Garis: pakai rule tebal 2px atau double rule ala koran. Radius = 0 (sudut tajam). Bayangan = hard offset, bukan blur.

05 — Print FX

Efek
cetak

Halftone

Titik-titik cetak untuk shading & tint. Warna via currentColor.

Misregistrasi

MISPRINT

Ghost pink+biru offset 2–3px. Dipakai untuk headline & aksen, jangan body.

Selotip & Cap

EvidenceClassified

Cap miring (multiply), selotip semi-transparan menahan foto.

Foto produk diperlakukan seperti fotokopi: grayscale kontras tinggi + halftone + sedikit miring + selotip. Motion: cepat & “snap”, bukan glow lembut. Hormati prefers-reduced-motion.

08 — Tokens

Tokens

File terpisah: tokens-riso.css. Nilai identik dipakai di design tool & kode.

:root{
  /* paper + ink */
  --paper:#F1E7D2; --paper-2:#E7DBBE; --ink:#161009; --ink-soft:#5A5142;
  /* spot inks */
  --pink:#FF2E88; --blue:#2436D8; --overprint:#7A1F9E; --acid:#E4EA1F;
  /* type */
  --f-display:"Anton"; --f-head:"Archivo Black"; --f-body:"Inter"; --f-mono:"Space Mono";
  /* print rules */
  --radius:0; --rule:2px solid var(--ink); --shadow-hard:6px 6px 0 var(--ink);
  --misreg: 3px 0 0 var(--pink), -3px 2px 0 var(--blue); /* text-shadow */
  --ease:cubic-bezier(.2,.8,.2,1);
}

Font asli hanya tampil bila dibuka online (Google Fonts). Offline → jatuh ke font sistem.
